02 / 当前在训练什么

模型：Qwen3.5-9B。先完成35步 LoRA，再从 base + LoRA 权重进入全参数微调；全参阶段使用新的 optimizer 和学习率计划，继承数据游标。4卡 × 每卡 batch 1 × 梯度累积8，名义每更新32个决策；不做样本 packing。

上下文上限262,144 token，不裁剪、压缩历史。课程为8个复杂度阶段，阶段内按长度分组。复杂度来自教师最后生成的可编辑 XML 的节点数 + 边数，不是金标 XML 输入。只使用轨迹，未把那5000余条金标图→XML对加入 SFT。

每10个全局更新保存 checkpoint（45、55、65…）。主训练固定 loss 评测点为231 / 462 / 693 / 924；当前不能把不同难度 batch 的训练 loss 当成同一批样本的能力变化。

04 / 真正送进 SFT 的样本

① 全部已知上下文系统指令、skill、原图/裁图、历史动作、工具结果、review反馈
② 因果 forward整段已知序列并行计算；每个位置只能注意到此前位置
③ 只对当前回答计 CE历史与图像位置 labels = -100；当前 generator 的目标 token 保留
④ 反向传播梯度仍可经上下文的注意力/KV路径传递到可训练参数
loss mask ≠ detach 上下文。这里是 completion-only loss，不是把历史整块 detach。上下文位置没有“直接预测它自身”的监督损失，但会影响后续回答，因此仍参与梯度链。全参阶段更新语言和视觉参数；LoRA阶段只更新选定的适配器。梯度 checkpointing 用重计算节省显存，不代表切断上下文。

可把 forward 类比为 teacher-forcing 的整段 prefill；训练时不先让模型自由生成整条轨迹。每个样本的真实 teacher 回答已知，拼到历史后计算因果 logits，再只为当前回答算 loss。reviewer 自身不训练，其反馈若出现在 generator 上下文中，也属于 masked 历史。

这些样本为展示而选择，非随机质量统计。图像是无损PNG预览；真正训练仍采用官方 processor 的图像策略。页面完整保留所选样本的规范化历史与目标，没有用截断的上下文冒充完整样本。原始消息中的历史思考如何保留，由 Qwen 模板决定；以“实际模板字符串”视图为准。
